## What/Why?
This PR adds comprehensive documentation, draft PR templates, and implementation guides for adding CATEGORIES model support to BigCommerce App Extensions. The documentation includes step-by-step guides for 5 separate PRs across different repositories (GraphQL schema, backend service, category-manager UI components, and shared components) to enable App Extensions on category list and detail/edit pages.
